# [AIコーディングエージェントB]（Codex）を GitHub PR レビューに組み込む

このテンプレートは **APIキー無し**での PR レビュー（= [定額サブスクリプション認証]）を主軸にします。

---

## セットアップ（概念）
1. ChatGPT 側で GitHub 連携（Connector）を有効化
2. Codex 設定で対象リポジトリの **Code review** を ON
3. PR コメントで `@codex review`（または自動レビューON）

---

## レビューガイドライン
Codex はリポジトリ内の `AGENTS.md` を探索し、**近い場所の指示を優先**してレビューします。

- ルート `AGENTS.md` … 全体のレビュー方針（P0/P1/P2、セキュリティ、テスト）
- サブディレクトリの `AGENTS.md` … その領域だけの追加ルール

---

## GitHub Actions による自動トリガ（任意）
`.github/workflows/ai_codex_cloud_review.yml` は、PR が開かれた/更新されたときに
**ボットが PR コメントに `@codex review` を投稿**します。

- これにより、レビュー依頼の手作業を削減できます
- すでにレビュー依頼コメントがある場合は二重投稿しないようにガードしています

> 注: Codex の GitHub レビュー機能が未設定の場合でも、このワークフロー自体は無害です（単にコメントが残るだけ）。
