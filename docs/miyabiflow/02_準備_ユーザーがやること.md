# 02 準備 — ユーザーがやること（コマンド不要）

ここは **あなたが自分でやる**部分です。難しい作業はありません。

---

## A. アカウントの準備（必須）
- GitHub アカウント（PR/CIのため）
- Claude Code（MAXプラン想定）にログイン
- ChatGPT（Proプラン想定）にログイン（Codexを使うため）

---

## B. Claude Code を開く（必須）
1) Claude Code を起動  
2) **プロジェクトフォルダ**を開く  
3) 画面右側（または上部）に「ツール実行（Bash）」の許可が出たら、まずは **Allow（許可）** を選ぶ

> ここで「許可しない」を選ぶと、AIがコマンドを実行できず、手動コマンドが必要になります。

---

## C. GitHub リポジトリを準備（必須）
初心者向けのおすすめは **GitHub Desktop（GUI）** です。

### C-1) すでにプロジェクトがローカルにある場合
- GitHub Desktop を開く
- “Add existing repository” でプロジェクトを追加
- “Publish repository” で GitHub に公開

### C-2) これから作る場合
- GitHub Desktop で “Clone repository”
- 新規で作るなら GitHub のWebでリポジトリ作成 → DesktopでClone

---

## D. “make ci” だけは必ず用意（重要）
この方式では `make ci` が **合否判定の唯一の入口**です。

あなたはコマンドを打たなくてよいですが、
- Claude Code に「`make ci` が動くようにセットアップして」と日本語でお願いできる状態にしてください。

例（Claude Codeへの指示）:
> 「このプロジェクトで `make ci` を実行して、必要ならMakefileやCIスクリプトを整えてください。私はコマンドを打てないので、必要な操作はあなたが実行し、許可が必要なら私がクリックします。」
