# 07 トラブルシューティング（初心者向け）

---

## Q1. Claude Code が「コマンドを実行できない」と言う
**原因候補**
- ツール実行の許可をしていない
- `.claude/settings.json` の deny が厳しすぎる
- 環境がロックされている

**対処**
1) 画面に許可ダイアログが出たら **許可**  
2) それでもダメなら Claude Code に言う:
> コマンド実行ができない理由を調べて、最小の修正（settingsの調整）を提案してください。私は許可のクリックだけします。

---

## Q2. `make ci` が無い/動かない
**対処**
Claude Code に言う:
> このプロジェクトに `make ci` を作ってください。言語に合わせた最小の lint/test/typecheck を統合してください。

---

## Q3. PRで `@codex review` しても反応がない
**原因候補**
- Codex側の GitHub 連携が未設定
- リポジトリの Code review がOFF

**対処（あなたがやる）**
- Codex settings を開いて GitHub 接続と Code review ON を確認
- もう一度PRコメントで `@codex review`

---

## Q4. 同じエラーでループする
**対処**
- 3回続いたらフェイルオーバー  
  - Claude Code に「引き継ぎパケット作成」を依頼
  - PRコメントで `@codex fix the CI failures`

---

## Q5. worktreeが増えて混乱した
**対処**
- まず “今やるタスク1つ” に絞る
- 終わったworktreeは Claude Code に頼んで整理:
> 終わったタスクのworktreeを整理して、残っているタスクだけ分かるようにして。
