# 00 MiyabiFlow（雅フロー）全体像（ターミナル中心 + スマホ補助）

このプロジェクトの標準運用は **MiyabiFlow（雅フロー）** です。

## 合言葉
**Plan → Worktree → TDD → Verify → Review → Merge**

- [AIコーディングエージェントA]（Claude Code）が実装（[生成タスク]）
- [AIコーディングエージェントB]（Codex）がレビュー/検証（[評価タスク]）
- [並列作業ツリー]（git worktree）でタスクを分けて並列化
- [品質ゲート]（`make ci`）に通らない限り「完了」にしない

## 重要な前提（初心者向け）
- ユーザーは **ターミナルにコマンドを打たない**。
  - 代わりに、Claude Code に **日本語で指示**し、AIがコマンドを実行する。
  - ユーザーは “許可” のクリックだけ行う。
- ただし開発そのものは **ターミナル中心**（Claude Codeを動かすため）。
- スマホは [コメント自動化実行基盤]（Claude Code Action）や `@codex review` の **コメント操作**に使う（補助）。

## 人間承認は最小にする（重要なものだけ）
レビュー差分の精読は求めない。その代わりに、次の3つだけは承認を取る：
1) 技術スタック変更（新規フレームワーク/DB/クラウド等）
2) 権限・コストに影響する設定（Secrets/外部連携）
3) 本番デプロイやデータ移行

それ以外は AI が自動で進め、ユーザーは最後に “マージしてOKか” だけ判断する。

## まずやること（最短）
- ターミナルで Claude Code を開く
- `/miyabiflow`（雅フロー起動）を実行
- 出てきた「ターミナル分割指示」と「コピペパック」に従う



## 入口（最短）
ターミナルで Claude Code を開き、これだけ実行します：

- `/miyabiflow <やりたいこと>`

すると、雅フローが次を自動生成します：
- 推奨のターミナル分割（画面幅/作業スタイルから自動最適化）
- worktree前提のタスク分解（1〜3時間単位）
- **コピペパック3セット**（Issue / Claude Code / PRコメント）
