# 06 最小コマンドと最小クリック操作（本当に必要なときだけ）

基本は **AIに頼む**ので、あなたがコマンドを打つ必要はありません。  
ただし、次の2ケースだけ例外が起きます:

- **ケースA:** Claude Code がツール実行を許可されず、AIがコマンドを実行できない  
- **ケースB:** そもそもPCに必須ソフト（git等）が入っていない

その場合に備えて、**最小**の手順を載せます。

---

## A) クリックが必要（ほぼ必須）
### 1) GitHubにログイン
- これはAIではできません（あなたがログインします）

### 2) PRを作る（Web）
- “Compare & pull request” を押す
- PRテンプレに沿って貼り付ける

### 3) CodexのGitHub連携（Codex settings）
- GitHubコネクタを有効化
- 対象リポジトリの “Code review” をON

---

## B) どうしても必要なコマンド（※あなたが打てないなら AI に貼って実行してもらう）
> **コツ:** 下のコマンドは「あなたがターミナルに打つ」ためではなく、  
> **Claude Code に貼り付けて“実行して”とお願いするため**に書いてあります。

### 1) gitが入ってるか確認
```bash
git --version
```

### 2) リポジトリを作る（既にあるなら不要）
```bash
git init
```

### 3) リモートを設定
```bash
git remote add origin <GitHubのURL>
```

### 4) 初回push
```bash
git add .
git commit -m "init"
git push -u origin main
```
