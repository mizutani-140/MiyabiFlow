# 01 はじめに — MiyabiFlow（雅フロー）って何？

コマンドを打たずに、AIに日本語で指示して進める開発運用

---

## 1) 何が嬉しいの？
初心者が「やり方が分からない」から抜け出すために、**手順と役割を固定**します。

- まず **計画（Plan）** を作る（いきなり書かない）
- 1つの作業を **1つの作業場所（worktree）** に分ける（混ざらない）
- **テストから書く（TDD）**（仕様が残る）
- **CI（make ci）に合格しないと終われない**（品質が担保される）
- 詰まったら **Codexが助ける**（フェイルオーバー）

---

## 2) 役割（覚えるのはこれだけ）
- Claude Code = **[AIコーディングエージェントA]**（作る人）
- Codex = **[AIコーディングエージェントB]**（チェックする人：レビュー/検証/テスト）

> 覚え方: **Aが作る、Bが壊してチェックする**。

---

## 3) あなた（ユーザー）がやることは最小
基本は **「日本語でAIにお願いする」** だけです。

あなたがやるのは主に:
- アプリにログインする
- “許可しますか？” のダイアログで **許可** を押す
- GitHubで **クリック**（PR作成・コメント）
- 最後に **Approve**（人間の承認）

---

## 4) 使う道具（ざっくり）
- GitHub（PRとCI）
- Claude Code（実装）
- Codex（GitHub上のレビュー、または補助）

---

## 5) 目標（最初の1周）
最初の目標はこれだけ:
1. 小さな機能1つを TDD で実装
2. PRを作成
3. CIが緑
4. `@codex review` でレビュー
5. 人間が承認してマージ
