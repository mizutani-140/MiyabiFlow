# [AI自律駆動開発システム] アーキテクチャ

## 全体像（抽象化）

- **[計画生成器]**: [要求定義] → [タスクDAG] → [並列作業ツリー]割当
- **[生成タスク]**: 主に [AIコーディングエージェントA]
- **[評価タスク]**: 主に [AIコーディングエージェントB] と CI
- **[品質ゲート付きデリバリーパイプライン]**: GitHub Actions + `make ci`
- **[決定論フック]**: Claude Code hooks でログ/危険操作ブロック/品質ゲート

## なぜ worktree を使うか
- 「並列に進めたい」要求と「コンフリクトしたくない」を両立するため。
- ブランチを複数同時に編集しても、作業ディレクトリが分離される。
